# 3) `CONTRIBUTING.md` (short)
Create `CONTRIBUTING.md`:

```markdown
# Contributing

Thanks for wanting to contribute! 🛠️

- Fork the repo.
- Create a branch: `git checkout -b fix/your-change`
- Make changes, add tests or examples if relevant.
- Commit with clear message and open a PR.
- For any destructive changes, explain safety considerations.

Please keep in mind this script performs deletions — make sure any change preserves a safe default (dry-run).
